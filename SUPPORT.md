# Support

This repository is published by commercetools as reference code. Read this
before you build on it.

**It is freely available, AS IS, and unsupported.** Specifically:

- **No SLA.** Nothing here is covered by a commercetools service-level agreement.
- **No security patching.** Dependencies are not monitored or patched on a schedule.
- **Not covered by commercetools Support.** Support tickets about this code will
  be closed with a pointer back here.
- **Issues are answered best-effort.** By the people who wrote it, when they have
  time. There is no on-call and no response-time commitment.
- **It may be archived without notice.** If it stops being useful, it goes
  read-only.

## What to do instead

- **Found a bug?** Open an issue. It will be read. It may not be fixed.
- **Need it fixed for a project?** Fork it. That is the intended use — this code
  exists to be copied and owned by you.
- **Need something supported?** Talk to your commercetools contact about the
  product equivalent.
